# turbo-garbanzo — тестовая сборка файтинга в стиле UFC 4 (Roblox)

**Быстрая тестовая сборка: ТОЛЬКО стойка.** Кадровая боевая система (startup/active/recovery), стамина, хитбоксы по костям R15, нокдауны, авторитетный сервер с фиксированным шагом 60 Гц, неподвижный манекен для отладки, HUD и телевизионная камера октагона.

Из полной MMA-версии вырезаны греппл, партер, предсказание на клиенте, ИИ-бот, тесты и инструменты калибровки. Что именно вырезано и как это вернуть из истории git — [`docs/ROADMAP.md`](docs/ROADMAP.md).

---

## Главный принцип: «физика» UFC 4 — это не физический движок

90% ощущений дают **кадры, тайминги и реакции**, а не симуляция тел:

| Система | Как сделано здесь |
|---|---|
| Фреймдата | `src/shared/FrameData.luau` + `data/moves.json` (60 fps) |
| Попадания | хитбокс на кости в активных кадрах → `HitboxSystem.queryHit` |
| Урон/блок/нокдаун | чистая функция `FrameData.resolveHit` |
| Стамина | `src/shared/StaminaSystem.luau` |
| Авторитет | сервер симулирует 60 тиков/с, клиент шлёт только `{action, moveId}` |
| Нокдаун | дёшево: `Humanoid.PlatformStand` + `ChangeState(Physics)`, подъём — `GettingUp` |
| «Вес» удара | хитстоп + тряска камеры + отбрасывание импульсом |

Roblox-физика используется **только** для knockback-импульса и падения при нокдауне.

**Ограничения сборки (обязательные):**

- только **R15**: хитбоксы варятся к костям `RightHand` / `LeftHand` / `RightFoot`, хуртбоксы — `Head` / `UpperTorso` / `LowerTorso`;
- клиент шлёт **только `{action, moveId}`** — урон считает сервер;
- логика боя на **фиксированном шаге 60 Гц**, не в плавающем Heartbeat-dt;
- **все числа боя** (тайминги, урон, стамина, баланс, хуртбоксы) — в `data/moves.json`, не в коде.

## Установка

Полный пошаговый гайд по Rojo — [`docs/SETUP.md`](docs/SETUP.md).

Коротко:

```bash
npm i -g rojo        # или: cargo install rojo / foreman
rojo serve           # в терминале
```

В Roblox Studio: **New Baseplate → Rojo plugin → Connect**. Или собрать файл места:

```bash
rojo build -o turbo-garbanzo.rbxlx
```

## Тренировочный ринг и короткий бой

При запуске сервера `RinkArena` один раз создаёт в Workspace чёрный мат, невидимые стены и стойку с ProximityPrompt. Подойди к стойке и нажми **E** (на геймпаде — X), чтобы войти: игрок телепортируется внутрь, появляется неподвижный манекен, включается камера на обоих бойцов и запускается таймер на 4 минуты. Кнопка **RUN FOR YOUR LIFE** или окончание таймера завершает сессию, удаляет манекен и возвращает игрока туда, где он стоял до входа.

Ринг генерируется из исходника `src/server/RinkArena.luau` автоматически один раз при старте сервера. Вручную собирать его в Studio не требуется. Сейчас предполагается один активный игрок за раз.

### Куда добавить свои анимации

Открой `src/client/AnimDriver.luau` и вставь ID в таблицу `M.ANIMATIONS`, например:

```lua
jab = "rbxassetid://1234567890",
```

Там уже есть 15 ключей: 12 движений (`jab`…`duck`) и `knockdown`, `getup`, `idle`. Анимации должны быть опубликованы для R15 и доступны игре. Пустые строки допустимы: для ударов и защит включаются встроенные авторские процедурные позы (перенос веса, поворот корпуса, замах, контакт, возврат в стойку). Это стартовые движения, не замена отполированным опубликованным клипам.

## 12 приёмов стойки (`data/moves.json`)

Удары: `jab`, `cross`, `hook_left`, `hook_right`, `uppercut_right`, `overhand_right`, `kick_low`, `kick_body`, `kick_head`.
Защита: `block` (удерживать), `slip`, `duck`.

Супер-армор есть у `overhand_right` (`props.armorFrames`) — попадание в эти кадры не прерывает замах.

## Раскладка управления

Клиент шлёт только `{action, moveId}`; раскладка печатается в Output при старте. `ButtonB` не используется — Roblox держит её под меню. Прыжок отключён (`jumpAction` отвязан, `JumpPower = 0`).

| Клавиатура | Действие | Геймпад |
|---|---|---|
| `J` | джеб | `R1` |
| `K` | кросс | `R2` |
| `U` / `I` | хук передней / задней рукой | `L1` / `D-pad →` |
| `O` | апперкот | `D-pad ←` |
| `P` | оверхенд | `R3` |
| `N` / `M` / `,` | лоу / боди / хэд-кик | `X` / `D-pad ↑` / `Y` |
| `B` / `V` | слип / дак | `A` / `D-pad ↓` |
| `Space` (удерживать) | блок | `L2` (удерживать) |
| — | движение стандартным контроллером | левый стик |

`ButtonB` намеренно не используется (занята меню Roblox).

## Подключение анимаций (необязательно)

В `src/client/AnimDriver.luau` впиши свои `rbxassetid://` в таблицу `ANIMATIONS` (15 слотов: 12 приёмов + `knockdown` / `getup` / `idle`). Без анимаций игра работает — логика считает кадры по `data/moves.json`; `AnimDriver.reportMissing()` печатает в Output, что не подключено.

## Структура

```
default.project.json      # маппинг Rojo -> Roblox
data/
  moves.json              # ★ ВСЕ числа боя: 12 приёмов + combat/balance/stamina/hurtboxes/dummy
  fighters.json           # статы бойцов/архетипов
src/
  shared/
    FrameData.luau        # ★ типы MoveDef/HitResult, фазы, resolveHit
    StaminaSystem.luau    # стамина, выдох, множители скорости
    FightMath.luau        # clamp/lerp/remap, поворот к цели
    Moves.luau            # загрузчик moves.json + Moves.isValid
    Remotes.luau          # единая точка RemoteEvent
  server/
    Main.server.luau      # вход: спавн бойцов, манекен, тик-цикл
    MatchServer.luau      # ★ фиксированный шаг 60 Гц, коллизии, снапшоты, античит
    FighterState.luau     # состояние бойца, буфер ввода, нокдаун, приём урона
    HitboxSystem.luau     # хитбоксы/хуртбоксы по костям R15
    DummyController.luau  # неподвижный манекен: static / blocks / fights
  client/
    Main.client.luau      # вход клиента
    InputBuffer.luau      # раскладка клавиатуры/геймпада -> намерения {action, moveId}
    CharacterControl.luau # автоповорот бойца к сопернику (~720 град/сек)
    AnimDriver.luau       # moveId -> Animation track (15 слотов, без анимаций работает)
    CameraRig.luau        # TV-камера октагона + тряска
    VFX.luau              # хитстоп, вспышки, брызги, звук
    HUD.luau              # полоски здоровья/стамины
tools/
  luau_syntax_check.py    # офлайн-проверка синтаксиса .luau (Luau -> Lua 5.1 + парсер)
docs/
  SETUP.md                # как работать через Rojo
  ROADMAP.md              # ★ что вырезано и как вернуть из истории git
```

## Что проверить в первую очередь

1. При Play появились манекен и HUD, в Output напечатаны сообщения старта.
2. Нажми `J` / `R1`: джеб должен снимать здоровье манекена.
3. Попробуй остальные удары и комбо через ввод в recovery-окно.
4. Удерживай блок и проверь уменьшенный урон и расход стамины.
5. Используй `B`/`A` (слип) и `V`/D-pad вниз (дак).
6. Повтори тяжёлые удары до нокдауна и дождись подъёма.
7. Включи режимы манекена и видимые хитбоксы командами ниже.

## Что работает «из коробки»

- ✅ Джеб прерывает кросс, потому что короче (7 vs 12 кадров startup) — прерывается **только замах**
- ✅ Супер-армор: `overhand_right` держит удар в кадрах `armorFrames`
- ✅ Блок режет урон по здоровью до `chipRatio`, но жжёт стамину ×1.35
- ✅ Долгий блок (>30 кадров) пробивается быстрее
- ✅ На нулевой стамине — выдох: скорость ×0.55, нокдаун-шанс растёт
- ✅ Один мув попадает максимум один раз (`hitConsumed`)
- ✅ Буфер ввода: нажал заранее — исполнится в окне отмены (как в файтингах)
- ✅ Нокдаун: `PlatformStand` + `Physics`, подъём — `GettingUp`
- ✅ Хитстоп 3 кадра (6 на нокауте) + тряска камеры
- ✅ Манекен с тремя режимами, всегда повёрнут к игроку
- ✅ Автоповорот бойца к сопернику на клиенте (~720 град/сек)
