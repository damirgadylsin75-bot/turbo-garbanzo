# TGRestore — видеть удалённые сообщения в Telegram (iPhone, rootless JB)

Твик для iOS (iPhone X / A11, iOS 16.7.10, jailbreak **Dopamine**), который
**показывает удалённые сообщения в Telegram** — восстанавливает их из локального
кэша устройства.

> Сборку сделать можно только на macOS (Theos + Xcode). Исходники готовы к компиляции.

---

## Что делает твик

1. **Кэширует текст сообщений**, которые открываются на устройстве (как входящих, так и исходящих).
2. **Когда сообщение исчезает из чата** (deleted for everyone / deleted for me), твик
   показывает его текст в виде восстановленного bubble на том же месте с подписью
   `👁 restored`.
3. **Визуально все сохранённые сообщения** — в окне «TGRestore» (кнопка 👁 в правом
   углу): текст, чат, время, кто открыл. Скопировать / переслать / очистить.

## Важно — что реально возможно, а что нет

Telegram удаляет сообщения **на сервере**. После удаления для всех контента ни на
устройстве, ни у других участников нет — восстановить его невозможно.

Твик может показать **то, что уже было загружено на это устройство**:

- ✅ Сообщения, которые вы **видели** (или которые лежали в локальном кэше истории чатов) —
  после удаления текст показывается из кэша TGRestore.
- ✅ Удалённое «для меня» сообщение, если его текст был захвачен до удаления.
- ❌ Сообщения, которые **никогда не загружались** на это устройство — их текст
  physically исчез с серверов, твик его не получит.
- ❌ Secret chats: удаление там стирает ключ расшифровки — восстановить нельзя (как
  и в оригинале).

Это объективное ограничение протокола Telegram, а не твик.

## Совместимость

| item | поддержка |
|---|---|
| Устройство | iPhone X (A11, arm64) — и другие arm64/arm64e |
| iOS | 15.x – 16.x (rootless). iOS 16.7.10 поддерживается Dopamine ≥ 2.5 / 3.x (A11 arm64: iOS 15.0 – 16.7.16) |

| Telegram | Современные сборки iOS (UIKit-level хуки — не зависят от внутренней структуры, работают на 11.x–13.x) |

## Сборка

### Вариант A — через GitHub Actions (без своего Mac)

В репозитории есть workflow `.github/workflows/build-deb.yml`:

1. Push ветки с твиком (или сделайте manual run: **Actions → Build deb → Run workflow**).
2. В отчёте workflow — артефакт **TGRestore-deb** → скачайте `.deb`.
3. На теги `v*` дополнительно создаётся релиз с `.deb`.

Workflow использует macOS-раннер, сам ставит Theos (`/opt/theos`) и iOS-SDK из Xcode.

### Вариант B — локально на macOS

```bash
# 1. Установить Theos (https://theos.dev) + Xcode command line tools
git clone https://github.com/theos/theos --depth 1 /opt/theos
cd /opt/theos && git submodule update --init --recursive

# 2. Собрать .deb для rootless jailbreak
cd tweaks/TGRestore
THEOS=/opt/theos ./build.sh
# → .theos/TGRestore-1.0-iphoneos-arm.deb
```

## Установка на Dopamine (iPhone)

**Способ A — через пакетный менеджер (Sileo/Zebra):**
залить `.deb` на любой HTTP-хостинг, добавить источник (репозиторий) в Sileo и
установить `com.turbogarbanzo.tgrestore`.

**Способ B — ручная установка (rootless):**
1. Разобрать deb: `ar x TGRestore-1.0-iphoneos-arm.deb`, `tar xf data.tar.*`
2. Скопировать `Library/Tweaks/TGRestore.bundle` на iPhone в
   `/var/jb/library/Tweaks/` (через palera1n/TweakUtil/Sileo-файловый менеджер)
3. Перезапустить Telegram.

## Использование

1. Запускаете Telegram — справа вверху появляется кнопка 👁.
2. Читаете чаты — твик невидимо кэширует текст сообщений (как только они появляются
   на экране).
3. Кто-то удаляет сообщение → на его месте появляется bubble с текстом и `👁 restored`.
4. Длинное нажатие на 👁 (или меню кнопки) → окно со всеми сохранёнными и
   восстанавленными сообщениями: копировать, переслать, очистить.
5. Настройки (в меню 👁): пауза кэширования, скрыть bubble, скрыть кнопку, очистить
   кэш.

## Как это работает (технически)

- `UILabel`/`UITextView` `setText:`/`setAttributedText:` — хуки ловят текст, когда он
  отрисовывается **внутри пузырька сообщения Telegram** (по классам узлов и структуре
  rounded-background). Записывается в JSON внутри контейнера Telegram
  (`Documents/TGRestore/messages.json`).
- `UICollectionView performBatchUpdates:completion:` — перед и после каждого batch
  делается снимок видимых bubble; если текст из кэша исчез — значит сообщение
  удалено → показывается restored bubble (в пространстве, которое освободилось
  после сдвига соседей).
- `UICollectionView setContentOffset:` — restored-bubble стираются при скролле (чтобы
  не накладывались на старые позиции).
- Кнопка 👁 + окно просмотра — чистая UIKit-UI, не касается логики Telegram.

Версия v1: восстановление выполняется через 1 сек. после batch (анимация удаления
около 0.8s); если вы быстро скроллите в этот момент, restore может пропуститься — это
защита от ложных срабатываний.

## Конфиденциальность

- TGRestore не делает network-запросов и не отправляет данные. Кэш лежит **только
  локально** в контейнере Telegram на этом устройстве.
- Чтобы удалить данные — «Clear cache» в меню или удалить файл
  `Documents/TGRestore/` в контейнере приложения.

## Disclaimer

Jailbreak и вмешательство в работу приложения — на ваш риск. Твик не меняет
работу Telegram на сервере, не крадет данные и не нарушает приватность других
пользователей — он показывает только то, что уже было на вашем экране.
